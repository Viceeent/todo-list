# To-do List

Its a Python Command-line to-do list application that allows the user to add tasks, mark them as completed, delete them and display what they currently have to do

## Project Background

I made this project back in December 2025 as part of my journey to learn python specifically while learning list of dictionaries.

## Features

- Adds new tasks to the to-do list.
- Stores each task with its completion status.
- Marks a selected task as completed.
- Deletes a selected task.
- Displays all current tasks.
- Shows whether each task is completed or uncompleted.
- Reports when a requested task cannot be found.
- Allows the user to continue using the program or quit.

## Technologies and Concepts

- Python
- Lists
- Dictionaries
- Lists of dictionaries
- Functions
- Loops
- Conditional statements
- Formatted strings

## How it works

Each task is stored as a dictionary containing the task description and a Boolean completion status. The dictionaries are inside of a list, the structure of each task is "{'task': 'Example task', 'done': False}"

## How to run it

1. Install Python
2. Save the program as "todo_list.py" or as whatever you want but ensure it's a .py file
3. Open a terminal in the folder containing the code
4. run it
